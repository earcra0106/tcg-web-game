# tutorial.test.ts

## 責務

チュートリアルのシナリオ導出、条件付き状態遷移、表示切替、動的文言と矢印対象をVitestで固定する。

## 関数仕様

### void describe('tutorial')

次を検証する。

1. 対象倉庫選択からステージ2目標料理指定までの成功イベントで、1〜16へ順に進み、配置した3設備のIDを保持する。
2. 異なる食材の倉庫など条件外のイベントでは元state参照を維持する。
3. ⑬でステージ2目標料理アイコンを開くと段階を維持したまま矢印だけを消す。
4. 表示オフ中も条件イベントで進み、表示はnullとなり、再オンできる。
5. ステージ2達成時は段階16・表示オフとなり、再オンすると終了文を返す。
6. ステージ目標から食材・料理・必要加工機のIDと名称を導出する。
7. タップ文言への切替と、⑭で選択モード済みの場合の矢印非表示を検証する。

UI側では `TutorialGuide.test.tsx` が改行・インラインアイコン・非表示・矢印座標を、既存のToolbar・StageHud・MachineHeldItemsテストが対象アンカーと初心者マークボタンを検証する。

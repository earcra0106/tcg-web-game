# tutorial.ts

## 責務

ステージ1・2の目標からチュートリアル用の食材・料理・加工機を導出し、16段階の進行状態、表示文言、誘導対象を純粋関数として管理する。表示のオン・オフと進行は分離し、オフ中も操作イベントによる進行を継続する。

## パッケージと自作範囲

- React、Drei、Lucide はフキダシ、3D座標上のDOMアンカー、既存ボタンと同じアイコンの表示に使う。
- チュートリアルの条件判定、文言、矢印位置の追跡はゲーム固有要件のため自作する。
- フキダシ位置はツールバー上の左詰めで固定され、矢印だけがDOMと3Dの対象を追跡するため、ツアー・フローティングUI用の追加パッケージは導入しない。

## 型仕様

- `TutorialStep`: 1〜16の数値リテラル。
- `TutorialStageScenario`: 目標料理ID・名称、単一の倉庫食材ID・名称、直接加工に必要な加工機ID・名称。
- `TutorialScenario`: `stageOne`, `stageTwo`。
- `TutorialState`: 現在段階、表示オン・オフ、ステージ1で配置した倉庫・出荷口・加工機ID、⑮で選択した加工機ID、⑬のレシピ矢印消去状態。
- `TutorialEvent`: 表示切替、ツール選択、正常配置、接続元選択、接続成功、加工機選択、目標レシピ表示、加工先指定、ステージ達成。
- `TutorialMessageToken`: 文字列または初心者マーク・コンベア・選択・倍速のインラインアイコン。
- `TutorialArrowTarget`: ツールボタン、モードボタン、配置機械、ステージ目標UI、目標料理アイコン、加工先指定ボタン。
- `TutorialView`: 段階、改行単位の文言トークン、任意の矢印対象。

## 関数仕様

### TutorialScenario createTutorialScenario(stageOneGoal, stageTwoGoal)

各目標の直接レシピから、単一の倉庫食材と加工種別に対応する加工機を導出する。対象が単一倉庫食材の直接加工レシピでなければ `Error('Tutorial requires a single storage ingredient recipe: '+foodId)`。

### TutorialState createInitialTutorialState()

段階1、表示オン、各配置IDなし、⑬の矢印未消去で初期化する。シード再挑戦では状態を維持し、ページを再読み込みした場合だけ再初期化する。

### TutorialState reduceTutorial(state, event, scenario)

現在段階と条件が一致する成功イベントだけを反映する。誤った対象、拒否された配置、失敗・逆方向の接続では元state参照を返す。`toggle` は段階を変えず表示だけ反転する。ステージ2達成は現在段階にかかわらず段階16・表示オフにし、その後の手動オンでは段階16を維持する。

### TutorialView | null createTutorialView(state, scenario, actionLabel, selectedTool)

表示オフならnull。表示オンなら現在段階の文言と矢印対象を返す。`actionLabel` は粗いポインターでは「タップ」、それ以外では「クリック」。⑭で既に選択モードなら矢印なし。

## UI連携仕様

- フキダシはツールバーの上に置き、左端をツールバーと揃える。表示対象の操作は妨げない。
- アクティブ対象に `data-tutorial-anchor="active"` を付け、矢印オーバーレイが毎フレーム矩形を追跡する。盤面機械にはDrei `Html` でアンカーを投影する。
- `arrow.png` は対象右下に置き、元画像の左上向きの先端を対象へ向けて明滅・浮遊させる。動きを減らすOS設定では静止表示する。
- 横スクロール外のツールボタンは対象変更時に表示範囲へ自動スクロールする。
- チュートリアルボタンはHUD内でヘルプボタンの直前に置き、初心者マーク、`aria-pressed`、状態に応じた操作名を表示する。
